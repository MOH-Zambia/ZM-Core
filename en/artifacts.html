Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

ZM-Core Adverse Event Profile

Zambia adverse event profile, including adverse events following immunization.
ZM-Core Allergy Intolerance Profile

Zambia allergy and intolerance profile for allergy substances, medicinal products, severity, and reactions.
ZM-Core Appointment Profile

Zambia appointment profile for scheduled clinical services, including SmartCare Pro appointments.
ZM-Core Care Plan Profile

Zambia care plan profile for treatment, nursing, and multidisciplinary plans.
ZM-Core Communication Audit Event Profile

Security and access audit trail for creation, routing, access, delivery, acknowledgement, or escalation of a hub communication.
ZM-Core Communication Consent Profile

An individual's consent decision governing whether and through which channels the Unified Health Communication Hub may make contact.
ZM-Core Communication Profile

The immutable delivery or receipt record produced for a communication request, including channel and delivery outcome.
ZM-Core Communication Provenance Profile

Record of who initiated or changed a communication workflow resource, when, and on whose behalf.
ZM-Core Communication Request Profile

A governed request from a Ministry health system to the Unified Health Communication Hub to route and deliver information.
ZM-Core Communication Subscription Profile

A secure R5 Subscription that activates a communication workflow when a governed communication topic matches.
ZM-Core Communication Subscription Topic Profile

A governed R5 subscription topic that describes which communication events may activate hub workflows and what may be filtered or returned.
ZM-Core Communication Task Profile

An acknowledgement, required action, recipient-resolution, or escalation task linked to a hub communication workflow.
ZM-Core Condition Profile

Zambia diagnosis/condition profile
ZM-Core Diagnostic Report Profile

Zambia diagnostic report profile for laboratory, imaging, pathology, and other diagnostic services.
ZM-Core Encounter Profile

Zambia health encounter profile
ZM-Core Facility Organization Profile

A health facility registered in the Zambia Master Facility List. Physical coordinates and site characteristics are represented by ZMCoreLocation, while offered services are represented by ZMCoreHealthcareService.
ZM-Core Healthcare Service Profile

A service directory entry used to resolve facilities, responsible teams, service coverage, and communication contacts.
ZM-Core Immunization Profile

Zambia immunization profile for vaccines administered to a patient.
ZM-Core Location Profile

A physical or administrative place from the Zambia Health Facility Registry used in facility and reporting-hierarchy routing.
ZM-Core Medication Dispense Profile

Zambia medication dispensing profile linking dispensed medicine to the prescription, patient, encounter, and dispensing facility.
ZM-Core Medication Profile

Zambia Core Medication Profile aligned to the ZAMMSA national product catalogue and the eLMIS Master Product List.
ZM-Core MedicationRequest Profile

Zambia medication request profile
ZM-Core Observation Profile

Zambia clinical observation profile
ZM-Core Organization Profile

Zambia healthcare organization profile, including identifiers and classifications used by the national Master Facility List.
ZM-Core Patient Profile

Zambia patient profile for use in health systems
ZM-Core Practitioner Profile

Zambia health workforce practitioner profile
ZM-Core Practitioner Role Profile

A current health-worker role used to route communications by responsibility rather than by hard-coded contact details.
ZM-Core Procedure Profile

Zambia procedure profile for surgical, diagnostic, therapeutic, and programme procedures.
ZM-Core Recipient Group Profile

A governed national, provincial, district, facility, patient, or workforce distribution group used for recipient resolution.
ZM-Core Related Person Profile

Zambia related person profile for next of kin, caregivers, guardians, treatment supporters, and patient-linked contacts.
ZM-Core Service Request Profile

Zambia request profile for laboratory, imaging, procedure, and referral services.
ZM-Core Specimen Profile

Zambia specimen profile for diagnostic sample collection, transport, receipt, and processing.

Structures: Extension Definitions

These define constraints on FHIR data types for systems conforming to this implementation guide.

Approved Communication Template

Identifier of the approved message template used to render the communication.
Communication Acknowledgement Required

Whether the workflow must create and track an acknowledgement or completion Task.
Communication Data Classification

The governance classification used to determine permitted channels and payload disclosure.
Communication Expiry

The instant after which the request must not be delivered and should be completed, revoked, or escalated according to policy.
Communication Fallback Channel

An approved alternative channel to try if the preferred channel cannot deliver the message. Repetition order expresses routing order.
Communication Message Language

BCP-47 language code in which the recipient-facing message is rendered.
Communication Requesting System

The authoritative source system that submitted the communication request to the HIE.
Consent Communication Channel

A channel for which the individual's contact consent decision applies.
Medication LSI Enabled

Indicates whether this medication is enabled for the Logistics Seasonality Index (LSI).
ZM-Core Facility Registry Status

The combined operational, licensing, registration, or record-quality status assigned to a facility by the Zambia Master Facility List. This is distinct from Organization.active, which indicates whether the FHIR record is in active use.
ZM-Core Medication ATC Classification

WHO ATC classification for the product.
ZM-Core Medication Alternate Name

Alternate or brand name of the medicine, if any.
ZM-Core Medication Alternate Pack Size

Alternate pack size description, if used in Master List.
ZM-Core Medication Archived

Indicates whether the product is archived or no longer active in the catalogue.
ZM-Core Medication Can Round To Zero

Indicates whether calculated order quantities can be rounded down to zero.
ZM-Core Medication Cartons Per Pallet

Number of cartons per pallet.
ZM-Core Medication Controlled Substance

Indicates whether the product is a controlled substance.
ZM-Core Medication Description

Long description of the product from the Master List.
ZM-Core Medication Dispensing Units

Unit in which the product is dispensed (e.g. tablet, vial, bottle).
ZM-Core Medication Dosage Unit

Unit of measure for the product strength (e.g. mg, ml, IU).
ZM-Core Medication Doses Per Dispensing Unit

Number of doses per dispensing unit.
ZM-Core Medication Flammable

Indicates whether the product is flammable.
ZM-Core Medication Full Name

Full trade name of the product as it appears in the Master List.
ZM-Core Medication Full Supply

Indicates if the product is part of the full-supply list.
ZM-Core Medication Generic Name

Generic name of the medicine.
ZM-Core Medication Hazardous

Indicates whether the product is hazardous.
ZM-Core Medication Level of Access

Level of access / level of care at which this medicine is used (e.g. Health Post, Clinic, Hospital).
ZM-Core Medication Light Sensitive

Indicates whether the product is light sensitive.
ZM-Core Medication MSL Pack Size (numeric)

Numeric MSL pack size (e.g. 100, 10).
ZM-Core Medication Pack Rounding Threshold

Threshold at which pack quantities are rounded up or down.
ZM-Core Medication Pack Size (text)

Pack size description (e.g. 'Pack of 100', 'Each').
ZM-Core Medication Pack Weight

Weight of a single pack, typically in kilograms.
ZM-Core Medication Packs Per Carton

Number of packs per carton.
ZM-Core Medication Price

Unit price of the product (e.g. pack price) as a Money value.
ZM-Core Medication Product Group

Programmatic grouping (e.g. ARV, TB, Malaria, RMNCH).
ZM-Core Medication Product Type

High-level product type (e.g. Medicine, Lab Reagent, Device).
ZM-Core Medication Route of Administration

Route of administration for this medicine (e.g. oral, IM, IV).
ZM-Core Medication Shelf Life

Product shelf-life description (e.g. 24 months).
ZM-Core Medication Storage Classification

Storage classification (e.g. Room temperature, Cold chain, Freezer).
ZM-Core Medication Storage Instructions

Free-text storage instructions.
ZM-Core Medication Store Refrigerated

Indicates whether the product must be stored refrigerated.
ZM-Core Medication Store Room Temperature

Storage temperature in degrees Celsius for room temperature storage.
ZM-Core Medication Strength

Product strength as free text (e.g. '500mg', '500mg/5ml').
ZM-Core Medication Tracer

Indicates whether the product is a tracer medicine.
ZM-Core Medication Transport Instructions

Free-text transport instructions.
ZM-Core Medication WHO Approved

Indicates whether the product is WHO prequalified / approved.
